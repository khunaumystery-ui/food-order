# 🔥 Shabu & Grill Palace - ระบบสั่งอาหารร้านบุฟเฟต์ & อะลาคาร์ท (Demo Prototype)

ระบบเว็บไซต์ร้านอาหารบุฟเฟต์และอะลาคาร์ทระดับพรีเมียม ออกแบบมาเพื่อนำเสนอเป็นตัวอย่าง (Demo / Interactive Prototype) ให้ลูกค้าและเจ้าของร้านอาหารดู สามารถเปิดใช้งานได้ทั้งบน **คอมพิวเตอร์, แท็บเล็ต, และโทรศัพท์มือถือจริง**

---

## 🌟 ฟังก์ชันครบถ้วนตามความต้องการ (Feature Checklist)

| ข้อ | ฟังก์ชัน | รายละเอียดการทำงานในระบบ Demo |
|---|---|---|
| **1** | **แยกบุฟเฟต์ & อะลาคาร์ท** | มีแท็บสลับ `บุฟเฟต์ (0฿ รวมในคอร์ส)` และ `อะลาคาร์ทพิเศษ (สั่งแยกตามราคา)` ชัดเจน ตะกร้าแยกคำนวณยอดเงินแต่ละประเภทอย่างโปร่งใส |
| **2** | **รูปภาพและราคาอาหาร** | รูปภาพเมนูอาหารความละเอียดสูง พร้อมราคาชัดเจน (฿) มีป้ายกำกับ HOT, เมนูแนะนำ, เลือกระดับความเผ็ด 🌶️ และระบุโน้ตถึงเชฟได้ |
| **3** | **เปลี่ยนได้ 3 ภาษา** | ปุ่มสลับภาษาที่มุมขวาบน 🇹🇭 ไทย / 🇬🇧 English / 🇨🇳 中文 เปลี่ยนทั้งชื่ออาหาร คำอธิบาย ปุ่ม และระบบแจ้งเตือนทันทีโดยไม่ต้องโหลดหน้าใหม่ |
| **4** | **ระบบจัดการหลังบ้าน (Admin CMS)** | เมนู `⚙️ จัดการหลังบ้าน` สามารถ: <br>• ➕ **เพิ่มเมนูใหม่** (ใส่ชื่อ 3 ภาษา, หมวดหมู่, รูปภาพ, ราคา)<br>• ✏️ **แก้ไขเมนู & ราคา**<br>• 🗑️ **ลบเมนู**<br>• 🔄 **เปิด/ปิด สินค้าหมด (Sold Out)**<br>• 🔄 **ปุ่มรีเซ็ตข้อมูลเริ่มต้น (Restore Defaults)** |
| **5** | **ระบบแจ้งเตือนออเดอร์สด** | จอครัว (KDS) อัปเดตแบบ Real-time: <br>• 🔔 **เสียงเตือนกระดิ่ง 2 โทน (Ding-Dong!)** สังเคราะห์ผ่าน Web Audio API<br>• 🔴 **การ์ดแจ้งเตือน Popup Toast**<br>• เวิร์กโฟลว์สถานะ: `รอดำเนินการ` ➔ `กำลังปรุง` ➔ `เสิร์ฟแล้ว` |
| **6** | **ระบบ QR Code สั่งอาหาร** | สร้าง QR Code แบบ SVG คมชัด ไม่ต้องพึ่งเน็ต สำหรับโต๊ะ 1 ถึง โต๊ะ 20: <br>• มีป้ายตั้งโต๊ะ 3 ภาษา พร้อมพิมพ์ (Print Ready)<br>• จำลองการสแกนกล้อง หรือคลิกเปิดลิงก์สั่งของโต๊ะนั้นๆ ได้ทันที |
| **7** | **ผังจัดการร้านสูงสุด 20 โต๊ะ** | หน้า `🏢 ผัง 20 โต๊ะ` แสดงสถานะทั้ง 20 โต๊ะแบบ Live Floor Plan: <br>• 🟢 โต๊ะว่าง <br>• 🔵 กำลังรับประทาน (แสดงเวลานับถอยหลังบุฟเฟต์) <br>• 🟡 ออเดอร์ใหม่รอดำเนินการ <br>• 🧾 คลิกดูประวัติการสั่งแต่ละรอบ, สรุปยอดบิลสุทธิ, และเช็คบิล/เคลียร์โต๊ะ |

## 🚀 วิธีเปิดใช้งานเพื่อนำเสนอลูกค้า (Quick Start)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์ `start.bat` (แนะนำที่สุด ⭐)
1. ดับเบิ้ลคลิกที่ไฟล์ **`start.bat`**
2. ระบบจะเปิดเซิร์ฟเวอร์จำลองและเปิด Browser ให้อัตโนมัติที่ `http://localhost:3000`
3. ในหน้าต่างสีดำ (Terminal) จะแสดงเลข **IP Wi-Fi (เช่น `http://192.168.1.126:3000`)**
4. **จุดเด่นสำหรับพรีเซนต์:** คุณสามารถให้ลูกค้านำมือถือจริงที่ต่อ Wi-Fi เดียวกัน มาสแกน QR Code บนหน้าจอคอมพิวเตอร์ เพื่อกดสั่งอาหารจากมือถือจริง แล้วจะเห็นออเดอร์เด้งเข้าจอคอมพิวเตอร์พร้อมเสียงกระดิ่งทันที!

### วิธีที่ 2: ดับเบิ้ลคลิกไฟล์ `index.html` โดยตรง (ไม่ต้องลงโปรแกรมใดๆ)
- ดับเบิ้ลคลิกไฟล์ **`index.html`** ในโฟลเดอร์นี้เพื่อเปิดใน Google Chrome หรือ Microsoft Edge
- ระบบทำงานได้สมบูรณ์แบบ แม้ไม่มีการเชื่อมต่ออินเทอร์เน็ต (มีระบบ BroadcastChannel จำลองการ Sync ข้ามหน้าต่างแท็บ)

## 💡 ลำดับขั้นตอนการนำเสนอลูกค้า (Presentation Flow)

1. **เปิดแถบ "ลูกค้าสั่งอาหาร (Customer Menu)":**
   - แสดงให้ลูกค้าเห็นความสวยงามระดับพรีเมียม รองรับทั้งบนคอมพิวเตอร์และกดปุ่ม `📱 กรอบมือถือ` เพื่อจำลองมุมมองสมาร์ตโฟน
   - กดปุ่มเปลี่ยนภาษา 🇹🇭 / 🇬🇧 / 🇨🇳 โชว์ความพร้อมในการรับนักท่องเที่ยวต่างชาติ
   - เลือกดูแท็บ **"บุฟเฟต์" (0฿ รวมในคอร์ส)** และแท็บ **"อะลาคาร์ท" (คิดราคาตามจริง)**
   - กดเลือกอาหาร เช่น เนื้อวากิว A5, กุ้งแม่น้ำ, ปรับระดับความเผ็ด 🌶️ แล้วกดเพิ่มลงตะกร้า

2. **เปิดหน้าจอสองหน้าต่างคู่กัน (Split Screen):**
   - หน้าต่างที่ 1: หน้าสั่งอาหารของ **โต๊ะ 05**
   - หน้าต่างที่ 2: หน้าจอ **👨‍🍳 จอครัว & แคชเชียร์**
   - พอกด "ยืนยันการสั่งอาหาร" ในหน้าต่างที่ 1 ➜ หน้าต่างที่ 2 จะมีเสียงกระดิ่ง "Ding-Dong!" 🔔 พร้อมออเดอร์เด้งขึ้นมาทันที

3. **เปิดแถบ "🏢 ผัง 20 โต๊ะ":**
   - โชว์ภาพรวมทั้ง 20 โต๊ะ โต๊ะไหนว่าง โต๊ะไหนกำลังทาน โต๊ะไหนมีออเดอร์เข้าใหม่
   - คลิกที่โต๊ะเพื่อเปิดดูสรุปบิล รายการอาหารที่สั่งไปทั้งหมด และปุ่มเช็คบิล

4. **เปิดแถบ "⚙️ จัดการหลังบ้าน (Admin CMS)":**
   - โชว์การกดเพิ่มเมนูใหม่ แก้ไขราคา เปลี่ยนสถานะเป็น "สินค้าหมด" เมนูในหน้าลูกค้าจะอัปเดตตามทันที

5. **เปิดแถบ "📲 QR Code โต๊ะ":**
   - โชว์ป้าย QR Code ทั้ง 20 โต๊ะ ดีไซน์พร้อมพิมพ์ไปตั้งบนโต๊ะอาหารในร้านได้ทันที

## 📂 โครงสร้างไฟล์ในโฟลเดอร์
- `index.html` - หน้าเว็บแอพพลิเคชันหลัก รวมทุกระบบไว้ในไฟล์เดียว รวดเร็ว ปรับแต่งง่าย
- `qrcode.min.js` - เอนจินสร้างภาพ SVG QR Code แบบออฟไลน์ 100% ไม่พึ่งพาเซิร์ฟเวอร์ภายนอก
- `server.js` - เซิร์ฟเวอร์ Node.js สำหรับรองรับการเชื่อมต่อข้ามอุปกรณ์มือถือจริงผ่าน Wi-Fi
- `start.bat` - สคริปต์คลิกเดียวรันระบบพร้อมเปิดเบราว์เซอร์
- `README.md` - เอกสารคู่มือและการนำเสนอ
